# Walkthrough - Fitur Pencarian Global (Global Search)

Website Anda kini dilengkapi dengan sistem pencarian pintar yang memungkinkan pengunjung menemukan konten apa pun secara instan menggunakan ikon kaca pembesar yang Anda berikan.

## Fitur Utama Pencarian

### 1. Ikon Pencarian di Navigasi
Ikon `magnifying-glass-bold.svg` kini terpasang di pojok kanan navigasi. Saat diketuk, ia akan memunculkan kolom input pencarian dengan animasi *slide-down* yang halus.

### 2. Kapsul Pencarian (Search Capsule)
Input pencarian muncul dalam bentuk "kapsul" *glassmorphism* di bawah navigasi. Anda bisa langsung mengetik untuk mencari.

### 3. Pencarian Menyeluruh (Smart Indexing)
Sistem secara otomatis mengindeks seluruh konten website:
- **Karya Galeri:** Mencari berdasarkan judul kategori.
- **Jurnal/Artikel:** Mencari berdasarkan **Judul**, **Kategori**, **Hashtag (#tag)**, bahkan **Isi Konten** di dalam file Markdown Anda.

### 4. Hasil Pencarian Real-time
Hasil pencarian akan tampil dalam *overlay* transparan yang elegan. Hasil dikelompokkan menjadi tipe "Karya" atau "Jurnal".
- Jika Anda mengklik hasil **Karya**, Anda akan diarahkan ke kategori galeri tersebut.
- Jika Anda mengklik hasil **Jurnal**, modal artikel akan langsung terbuka (jika Anda sedang di halaman jurnal) atau Anda akan diarahkan ke halaman jurnal.

## Cara Menggunakan

1. **Klik Ikon Kaca Pembesar** di menu navigasi atas.
2. **Ketik Kata Kunci** (misal: "puisi", "senja", atau "#alam").
3. **Pilih Hasil** yang muncul untuk langsung menuju ke konten tersebut.

---
*Fitur ini membuat website Anda jauh lebih mudah dijelajahi seiring bertambahnya koleksi karya dan tulisan Anda.*
